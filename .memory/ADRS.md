- [2026-07-07] [Claude] [ACTIVE] [DECISION] Chat Conversation↔Analysis Ownership Binding (ADR 009). Rationale: `POST /api/chat/conversations` wrote a client-supplied `analysisId` via the service-role client (RLS bypassed) with no ownership check — an IDOR letting any user bind a chat to another user's private analysis (root cause of the observed "double leak" — chat answering about a wrong/different video). Alternatives: RLS-only enforcement (rejected — this path uses the service client specifically to bypass RLS for legitimate S2S writes elsewhere, so RLS gives zero protection here; the check must be explicit application code).
