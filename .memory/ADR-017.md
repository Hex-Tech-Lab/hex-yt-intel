# ADR-017: Error Recovery in Async Hooks

**Date**: 2026-07-19  
**Status**: ✅ Implemented  
**Context**: Dashboard async hooks (auto-restore, digest) lack error resilience, causing silent failures and 500 errors in browser contexts  

## Problem

After P2 merges, new hooks in DashboardContainer execute critical async operations without proper error context:

1. **useAutoRestoreAnalysis** (inline in DashboardContainer) — fetches `/api/analyses/check` to auto-restore cached analyses
2. **useExecutiveDigest** (inline in DashboardContainer) — fetches `/api/analyses/digest` to generate executive summary

These operations had:
- ✅ Try/catch blocks (basic error handling)
- ✅ Cancelled flag (prevent state updates after unmount)
- ❌ No timeout protection for retries
- ❌ No error boundary to catch React-level rendering errors
- ❌ No retry logic for transient failures
- ❌ Silent failures swallowed in catch blocks

**Impact**: Unhandled errors crash React component tree → 500 on dashboard when Playwright/JavaScript runs, while direct HTTP requests work (no JS execution).

## Solution

### 1. Error Boundary Component
Create `web/components/common/DashboardErrorBoundary.tsx`:
- Class component with `getDerivedStateFromError()` and `componentDidCatch()`
- Renders fallback UI when rendering errors occur
- Captures errors to Sentry with context
- Provides "Reload Dashboard" button for recovery

### 2. Digest Retry Logic
Enhance digest fetch in DashboardContainer:
- Implement retry loop: `[0, 3000, 5000, 8000, 13000, 21000]` ms
- Add 60s total timeout (prevent indefinite retries)
- Differentiate transient (5xx, 408, 429) vs permanent (4xx) errors
- Log retry attempts and final status
- Only retry on transient errors; fail fast on permanent errors

### 3. Improved Error Logging
- Add Sentry capture for auto-restore failures
- Include component context and operation tag
- Use console.error for critical failures; console.debug for debug info
- Check `cancelled` flag before logging to avoid noise after unmount

## Consequences

### Positive
✅ Dashboard remains functional even if async operations fail  
✅ Transient errors retry automatically with exponential backoff  
✅ Permanent errors fail fast without wasting retries  
✅ Errors logged to Sentry for observability + alerting  
✅ Error boundary catches unexpected React errors  
✅ Users see fallback UI instead of blank page  

### Tradeoffs
⚠️ Adds ~70 lines to DashboardContainer (retry loop + logging)  
⚠️ New error boundary component (~50 lines)  
⚠️ Requires Playwright testing to verify error scenarios  
⚠️ Retry delays (max 45s before final timeout at 60s) may feel slow to users

### Timeout Protection
```
Total retry time: 0 + 3 + 5 + 8 + 13 + 21 = 50s max wait
Hard cutoff: 60s absolute maximum
If 60s exceeded → break retry loop, show no card
```

### Retry Logic
```
for (attempt = 0 to 5) {
  if (Date.now() - start > 60000) break;
  
  fetch('/api/analyses/digest');
  
  if (5xx || 408 || 429) continue;  // retry
  if (4xx) break;  // fail fast
}
```

## Prevention: Hook Template

For future async data fetching hooks, use this template:

```typescript
import { useEffect, useRef, useState } from 'react';
import * as Sentry from '@sentry/nextjs';

interface UseAsyncDataReturn<T> {
  data: T | null;
  loading: boolean;
  error: Error | null;
}

export function useAsyncData<T>(
  key: string | null,
  fetchFn: (key: string) => Promise<T>
): UseAsyncDataReturn<T> {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<Error | null>(null);
  const fetchedRef = useRef<string | null>(null);

  useEffect(() => {
    if (!key || fetchedRef.current === key) return;
    fetchedRef.current = key;

    let cancelled = false;
    setLoading(true);
    setError(null);

    void (async () => {
      try {
        const result = await fetchFn(key);
        if (cancelled) return;
        setData(result);
      } catch (err) {
        if (cancelled) return;
        const error = err instanceof Error ? err : new Error(String(err));
        setError(error);
        Sentry.captureException(error, { tags: { hook: 'useAsyncData', key } });
        console.error(`[useAsyncData] ${key} failed:`, error);
      } finally {
        if (!cancelled) setLoading(false);
      }
    })();

    return () => { cancelled = true; };
  }, [key, fetchFn]);

  return { data, loading, error };
}
```

Then wrap component in error boundary:

```typescript
import { DashboardErrorBoundary } from '@/components/common/DashboardErrorBoundary';

export function MyComponent() {
  return (
    <DashboardErrorBoundary>
      {/* component JSX */}
    </DashboardErrorBoundary>
  );
}
```
