## Fix, in order, each with a real test (negative control: reproduce bug pre-fix, prove fix post-fix):

1. **P0 CAS race** (`SupabasePersistenceAdapter.ts`, `route.ts`, `AnalysisPersistencePort.ts`): `markChunkFailed()` only matches `(analysis_id, chunk_index, status='completed')` — a concurrent valid rewrite between read and demote gets wrongly demoted, and `chunkMap` entry is deleted regardless of CAS outcome. Pass an observed row version/updated_at/payload-fingerprint into the predicate; on CAS miss, refetch and reconcile (restore valid payload into chunkMap) before deleting; on DB error, don't delete the map entry — leave the row status indeterminate, don't let parent-finalize treat it as settled.
2. **P1 swallowed demotion error**: `markChunkFailed()` error is caught+swallowed then chunk removed from chunkMap and finalize proceeds — DB row stays completed+malformed while parent commits without it. Retry with bounded backoff; if still failing, abort/defer finalization with an observable failure (don't finalize silently).
3. **P1 primitive JSON crash**: `'dimensions' in chunk.payload` throws on a primitive (string/number/boolean/null) payload from a legacy row. Add shared `isRecord`/`hasUsableDimensions` predicate, use everywhere this check happens. Test string/number/boolean/null/array/{}/{dimensions:"bad"}.
4. **P1 crash-window side-effects**: parent CAS write and downstream side effects (transcript/cache/quota/QStash) aren't one atomic unit — a crash between them leaves them permanently missing. Add a durable side-effect claim/idempotent-outbox pattern recorded with the parent transition, OR at minimum a reconciliation-job hook point + failure-injection test proving the gap is detectable. Use judgment on scope — full transactional outbox may be too large; a documented, testable partial mitigation is acceptable if full scope is unreasonable for this PR, but say so explicitly in the report.
5. **P2 useAuxElementStatus.ts:112**: normal (non-StrictMode) mount with a rejected/non-OK fetch has no retry — schedule exactly one bounded retry with cleanup/cancellation, preserve the one-shot success guard, no retry loops. Test normal-mode rejection + non-OK + unmount-before-retry + eventual success.
6. **P3 log misclassification** (route.ts ~532): `isPayloadlessChunk ? 'payload-less' : 'malformed-object'` — malformed objects also have `validPayload` undefined so always mislabeled payload-less. Fix to `chunkPayloadMalformed ? 'malformed-object' : 'payload-less'`, add assertion test.
