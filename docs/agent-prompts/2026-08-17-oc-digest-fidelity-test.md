## 1. Context
hex-yt-intel is a YouTube-analysis SaaS. We're deciding whether GPT-OSS-120B (cheap/fast) can replace Haiku 4.5 (current model) for the Dimension-0 "Executive Digest" pass — a post-synthesis summarization step defined in `web/lib/prompts/executive-digest.ts`. `buildExecutiveDigestUserMessage(analysisMarkdown)` takes the already-assembled 11-dimension UCIS markdown as input and produces a 4-tier digest (0.1 Snapshot / 0.2 Overview / 0.3 Key Takeaways / 0.4 Detailed Summary), parsed by `parseExecutiveDigest()` in the same file. We have real historical rows in Supabase where this digest was already generated by Haiku 4.5 — this task compares GPT-OSS-120B's output against that real historical baseline, same input, same prompt, to measure fidelity (does it reproduce comparable format and content), not a synthetic benchmark.

This is distinct from the already-completed multilingual accuracy test (`docs/research/2026-08-17-multilingual-accuracy-testing.md`), which tested Haiku 4.5 only. This test is Haiku-4.5-baseline vs GPT-OSS-120B, same real inputs.
