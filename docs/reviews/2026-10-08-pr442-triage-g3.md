## Behaviour changes

1. `GroundedExtractionEngine.parseAndValidate` — payload with neither `claims` nor `unknowns` arrays (e.g. `{}`, truncated output) now throws `GroundedExtractionError` instead of flushing an empty ghost row.
2. `GroundedExtractionEngine.parseAndValidate` — claim with absent/non-numeric `confidence` scores 0.5 (was: 0 would only appear via clamp; absent defaulted to certainty-adjacent handling — now explicitly mid-range).
3. `ProjectiveSynthesisEngine.parseAndValidate` — empty `synthesis` object now throws; `coreThesis` must cite ≥1 valid claim ID when Part A produced ≥1 claim; malformed (null/non-object) projection entries are skipped with a warn instead of throwing.
4. `EpistemicPipelineDispatcher` — omitted `persistGhostRow` now reports failure (`false` + warn) instead of fabricated success; buffer cleanup runs even when no sensor provider is configured; buffer-only inputs mark sensors degraded instead of silently heuristic-routing.
