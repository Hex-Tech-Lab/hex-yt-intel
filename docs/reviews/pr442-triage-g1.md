## Behaviour changes

1. **Diarization metrics semantics changed** (intended, bug fixes): speaker speaking-time is now true wall-clock union (overlapping same-speaker words counted once); `overlapRatio` unioned across speaker pairs (N-way overlap counts once, not C(N,2) times). Existing callers consuming `turnEntropy`/`overlapRatio` will see different (more correct) values; both adapters delegate to the shared reducer so behaviour is uniform.
2. **AssemblyAI submissions now send `speech_model`** from adapter config (default unchanged: Universal path) — API contract change toward the provider, gated by config.
3. **Timeout precedence**: cascade remaining budget no longer overrides a shorter adapter-configured timeout (`min()` clamp). Long-cascade scenarios can now abort earlier than before if the per-adapter timeout is the binding constraint.
4. **Deepgram non-2xx read-abort reclassified as timeout (408)** instead of surfacing the HTTP status — affects error classification/tags only.
5. **Security redaction**: provider error text (AssemblyAI/Deepgram/DiarizationFactory Sentry + console paths) has URLs replaced with `[redacted-url]`; `redactMediaUrl` no longer logs URL parse errors. No functional change to success paths.
