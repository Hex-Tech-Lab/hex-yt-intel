## Behaviour changes

1. `MultimodalProbeRunner.inspectSingleChunk`: schema-invalid model output (non-boolean `uiFramesDetected`/`debateProsodyDetected`) now throws fail-closed instead of being coerced to `false`/0 (was silently feedable into the S1-S6 router as "no UI, no debate").
2. `MultimodalProbeRunner`: upstream error bodies embedded in probe error messages (→ Sentry) are capped at 2000 chars.
3. `MultimodalProbeRunner`: the model id sent to the provider is trimmed.
4. `sampler.calculateProbeTimestamps`: runs of probe starts whose windows overlap within one 15s chunk length collapse to the earliest start (16s clip → 1 probe, not 3).
5. `JevTextParser.analyze`: block scores are length-weighted; a short trailing block no longer counts as a full 8000-char block vote.

No test was weakened or deleted; no suppressions added. All fixes verified against existing + new regression tests.
