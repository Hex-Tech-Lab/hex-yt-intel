| 424 | P2 | V08 State Finality / V04 Concurrency | web/lib/adapters/SupabaseAuxRemediationAdapter.ts:249-274 | LATENT: `finishSampleRun` (line 258: `status: params.status`) writes `status='completed'` via `.in('status', ['pending','sampling'])` at line 273. `failStaleSystemSampleRuns` (lines 222-240, added by this PR) marks any pending/sampling run older than 30 min as `failed` on EVERY subsequent enqueue attempt.
